디자인 진단 & 사무형 ERP 개선안

현재 팔레트(웜 브라운 · 아이보리)는 그대로 유지합니다. 문제는 색이 아니라 색의 사용량, 위계, 정렬, 밀도입니다. 갈색을 넓은 면(테이블 헤더 · 모든 버튼)에서 걷어내고 강조에만 남기면, 같은 색으로도 사무용 ERP 톤이 나옵니다.

1. 진단 현재 화면에서 미숙함이 느껴지는 지점 10가지
현재 화면 전체 (19장)
1브랜드 컬러가 면적을 다 먹음
테이블 헤더 RGB(62,52,43) 풀필 + 모든 버튼이 갈색 채움. 강조색이 강조 기능을 잃었습니다.
개선 헤더는 #F2EEE7 + 회색 텍스트. 갈색은 Primary 버튼 1개, 선택 행, 링크에만.
2버튼에 위계가 없음
단가 관리의 «법인 추가 / 단가 추가 / 법인 수정 / 법인 삭제» 4개가 전부 동일한 Primary. 파괴적 동작이 추가 동작과 같은 무게입니다.
개선 Primary(채움) 1개 · Secondary(외곽선) · Ghost(텍스트) · Danger(테두리 적색) 4단계.
3디스플레이 폰트를 UI 전역에 사용
Gmarket Sans는 헤드라인용 서체입니다. 금액 숫자 폭이 들쭉날쭉해 표에서 자릿수 비교가 안 됩니다.
개선 본문 Pretendard(대체: 맑은 고딕), 숫자는 tabular 고정폭. Gmarket은 로고에만.
4금액 컬럼 노란 배경
합계·입금·미수금 3개 열을 통째로 RGB(255,248,230)로 칠해 표가 얼룩집니다.
개선 배경 제거 → 우측 정렬 + 굵기로 구분. 실제 강조가 필요한 «미수금» 한 열만 색 텍스트.
5«-»로 채운 빈 행
엑셀 공백 행이 그대로 «-» 행으로 들어와 24건짜리 표가 40행처럼 보입니다.
개선 프리젠터 단계에서 공백 행 제거, 법인이 바뀌는 지점에만 그룹 구분선.
6컨트롤 높이가 제각각
28 / 24 / 34 / 38px가 한 화면에 섞여 있습니다(TAECHANG_*_HEIGHT). 라벨 폭도 46/70/90/116px로 통일되지 않음.
개선 컨트롤 높이 32px 단일, 라벨 폭 80px 고정, 간격 4pt 배수만 사용.
7사이드바가 창 끝까지 안 닿음
좌측 트리 패널이 하단 20px를 남기고 끊기며 외곽선이 드러나, 창에 «얹힌» 느낌을 줍니다.
개선 사이드바는 상태바 위까지 full-bleed, 내부 패딩으로만 여백. 선택 항목은 좌측 3px 액센트 바.
8빈 상태 = 빈 격자
단가 데이터 관리 진입 시 40행짜리 빈 그리드가 화면을 채웁니다. 무엇을 해야 하는지 알려주지 않습니다.
개선 격자 대신 안내문 + 1차 액션 버튼을 표 영역 중앙에 배치.
9아이콘 체계 부재
검색만 비트맵 돋보기, 초기화는 유니코드 ↺, 법인 선택은 … 글자. 크기·굵기가 전부 다릅니다.
개선 16px · 1.5px 선 아이콘 세트 하나로 통일(검색/새로고침/추가/삭제/더보기/내보내기).
10작업 결과 요약이 없음
건수·합계·실패 건수를 OS 기본 상태바 «완료» 한 단어로만 알립니다.
개선 표 상단에 결과 바(총 건수 · 미수금 합계 · 기타 처리 법인), 하단 상태바는 진행/경로 전용.
