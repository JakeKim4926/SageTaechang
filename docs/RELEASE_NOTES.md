# Release Notes

SageTaechang 버전별 변경 이력입니다.
분류는 `기능` / `개선` / `버그` / `문서` 중 하나로 표기합니다.

---

## v2.0 (2026-08-21)

화면 전반을 디자인 개선안(목업) 기준으로 다시 맞춘 릴리스입니다. 업무 흐름은 그대로이고 표시와 구조가 바뀌었습니다.

### 기능
- [기능] 로그인·권한 — 관리자/사용자 2역할, 비밀번호 변경
- [기능] 워크플로 실행 상태를 카드 하나로 연속 표시(대기 · 처리 중 · 완료 · 실패), 완료 시 「폴더 열기」
- [기능] 실행 기록을 텍스트 로그에서 5컬럼 표로, 전체·성공·실패 필터 추가. **산출물 단위로 기록**해 파일 3건을 만들면 3행이 남습니다
- [기능] 미수금 결과 표에 요약 바(상단)와 합계 밴드(하단) 추가
- [기능] 표 선택 바 — 「N건 중 M건 선택됨」과 생성 버튼의 선택 건수 반영
- [기능] 견적서 「한 페이지 작성」 6행 제한을 상시 안내
- [기능] 미수금 데이터 관리에서 법인 출력 순서를 위아래로 이동
- [기능] 앱 스타일 메시지 박스 — 시스템 창을 앱 서체·색·버튼으로 교체(`AfxMessageBox` 56곳 중 55곳)
- [기능] 단가 법인을 별도 테이블에 저장 — 단가 0건 법인도 남습니다

### 개선
- [개선] 서체를 Pretendard로 전환(TTF 임베드, 미설치 PC에서도 동일)
- [개선] 색 사용량 정리 — 표 헤더·금액 컬럼의 갈색 면을 걷어내고 강조는 Primary 버튼·선택 항목·선택 행으로 한정
- [개선] 컨트롤 높이 32 통일, 폼 라벨 폭 통일, 표 행 높이 34와 가로 hairline
- [개선] 표 선택 행을 눈에 띄는 색과 좌측 카멜 바로 구분
- [개선] 다이얼로그 7종을 공통 프레임(캡션바)으로 통일하고 입력 검증을 인라인 에러로 이관
- [개선] 검색 UI 3곳을 기준·입력·검색이 한 테두리에 담긴 통합 박스로 통일
- [개선] 단가 데이터 관리 상세 카드를 인라인 편집 폼으로 정리, 빈 상태 안내 추가
- [개선] 아이콘을 직접 그린 세트로 통일(유니코드 글리프 제거)
- [개선] 표 행 삽입 중 리페인트 억제로 목록 갱신 체감 속도 개선

### 버그
- [버그] 라벨·콤보·버튼의 세로 중심이 어긋나던 문제 — 콤보 닫힌 높이를 실측해 32로 맞춤
- [버그] 폼 라벨 열이 행마다 어긋나던 문제(손보정 상수 제거)
- [버그] 에딧박스에서 Ctrl+A 전체 선택이 안 되던 문제
- [버그] 표 첫 열 커스텀 드로잉이 체크박스를 삼키던 문제
- [버그] 카드 헤더 밴드가 카드 테두리를 덮던 문제(3화면)
- [버그] 비활성 에딧박스가 활성과 같아 보이던 문제
- [버그] **이름 정리(`Taechang` → `Sage`)가 DB 테이블 이름까지 바꿔 기존 데이터가 보이지 않던 문제** — 시작 시 옛 이름 테이블을 새 이름으로 이어줍니다. 옛 테이블은 지우지 않습니다

### 문서
- [문서] 디자인 적용 계획(`DESIGN_PLAN`)·구조 리팩토링 계획(`REFACTORING_PLAN`)·기술부채 로그 운영

### 업그레이드 안내
- 기존 DB 파일을 그대로 씁니다. 첫 실행에서 테이블 이름 마이그레이션이 자동으로 돌고, **옛 테이블은 삭제하지 않습니다**
- 업그레이드 전 `data\estimate.db`를 복사해 두시고, 첫 실행 후 **법인 목록이 예전과 같은지** 확인하시기 바랍니다
